# Техническое задание
## Android-приложение для локального текстового и голосового общения с LLM

### 1. Назначение

Разработать пилотное Android-приложение для локального общения с LLM через текстовый и голосовой интерфейсы.

Приложение должно работать полностью локально, без обращения к внешним AI-сервисам.

### 2. Технологии

- **LLM:** Qwen3-0.6B-Instruct, квантование Q4_K_M, формат GGUF.
- **Движок LLM:** llama.cpp с поддержкой Android ARM64, выполнение на CPU без обязательного GPU.
- **Распознавание речи:** Vosk — локальная библиотека преобразования речи в текст.
- **Платформа:** Android.
- Использовать лёгкие библиотеки и локальное выполнение моделей.

**Требования к Qwen:**
- Модель должна храниться и выполняться непосредственно на устройстве.
- Работа без подключения к интернету после установки приложения и модели.
- Поддержка текстового диалога на русском языке.
- Поддержка контекста предыдущих сообщений текущей сессии.
- Ограничение размера контекста для снижения потребления оперативной памяти.
- Генерация ответа без обращения к внешним API.
- Поддержка продолжения ранее сохранённых диалогов.
- Для пилотной версии использовать одну модель Qwen3-0.6B в Q4_K_M.

### 3. Пользовательский интерфейс

Интерфейс диалогов должен быть максимально приближен к ChatGPT.

**3.1. Экран списка диалогов**

- Отображение существующих диалоговых сессий.
- Открытие выбранной сессии.
- Продолжение ранее начатого диалога.
- Удаление сессии.

**3.2. Экран диалога**

- Отображение полной текстовой истории выбранной сессии.
- Поле ввода текста в нижней части экрана.
- Кнопка очистки поля ввода.
- Кнопка записи голоса.
- Кнопка отправки сообщения.
- Возможность продолжать переписку в существующей сессии.

### 4. Голосовой ввод

1. При нажатии кнопки записи начинается запись голоса.
2. Во время записи отображаются кнопки:
   - **Отменить** — отмена записи.
   - **Завершить** — остановка записи.
3. После завершения записи Vosk преобразует аудио в текст.
4. Распознанный текст помещается в поле ввода сообщения.

### 5. Обработка сообщений

- Пользователь отправляет текстовое сообщение.
- Локальная Qwen обрабатывает сообщение и формирует ответ.
- Ответ отображается в текстовом диалоге.
- История сообщений сохраняется в рамках соответствующей сессии.

### 6. Структура проекта и CI/CD

- Проект должен содержать исходный код Android-приложения.
- В репозитории GitHub должен находиться YAML-файл конфигурации GitHub Actions.
- GitHub Actions должен автоматически собирать установочный APK-файл Android-приложения.

### 7. Скрипт установки

В корне проекта должен находиться PowerShell-скрипт (расширение `.ps1`) для установки приложения на подключённый Android-телефон. Скрипт выполняется на Windows.

**Поиск ADB:** в начале скрипта задаётся переменная с путём к ADB Tools (по умолчанию `%LOCALAPPDATA%\Android\Sdk\platform-tools`). Скрипт использует ADB из системной переменной `PATH`, если он там есть; если нет — из пути, заданного в переменной скрипта.

**Алгоритм работы скрипта:**

1. Найти подключённое Android-устройство.
2. Предполагается, что подключено ровно одно устройство.
3. Найти ранее установленную версию приложения.
4. Удалить установленное приложение.
5. Установить новый APK.
6. Вывести в консоль результат установки и сообщение об успехе.
7. Не закрывать консоль до подтверждения пользователя.

### 8. Результат

Готовый проект должен включать:

- Исходный код Android-приложения.
- Локальную интеграцию Qwen и Vosk.
- Интерфейс управления диалогами и голосового ввода.
- YAML-конфигурацию GitHub Actions для сборки APK.
- PowerShell-скрипт (`.ps1`) переустановки приложения на подключённом устройстве.
