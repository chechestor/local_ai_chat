# Local AI Chat — контекст проекта

Пилотное Android-приложение для текстового и голосового общения с LLM полностью на устройстве, без внешних AI-сервисов.
LLM — Qwen3-0.6B-Instruct (GGUF, Q4_K_M) через llama.cpp на CPU (ARM64); распознавание речи — Vosk.
Интерфейс диалогов — как у ChatGPT: список сессий, экран диалога, голосовой ввод. Язык диалога — русский.
Сборка APK — GitHub Actions; установка на телефон — PowerShell-скрипт `install.ps1` в корне репозитория.

## Где что

## Работа в роли

1. Прочитать `.team/team/common.md`.
2. Прочитать `.team/team/<role>/agent-instruction.md` и `.team/team/<role>/notes.md`.
3. Новые уточнения владельца сразу записывать в `notes.md` своей роли.

## Неснимаемые правила

Без явного «да» владельца в текущем разговоре нельзя:

- `push --force`, переписывать историю git, удалять или создавать ветки (ветка одна — `main`; обычные коммит и push в `main` разрешены);
- удалять данные и файлы вне рамок задачи;
- добавлять зависимости, менять схему БД;
- публиковать (релизы, пакеты, посты), отправлять письма и сообщения;
- оплачивать что-либо, подключать платные API;
- обращаться к внешним AI-сервисам из приложения (противоречит ТЗ).

Секреты не печатать и не вводить; не класть в notes, бэклог, коммиты.
